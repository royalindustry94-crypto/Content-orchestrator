## Immediate escalation triggers

- Security regression or Critical/High open at release time
- Tenant isolation / RLS weakness
- Spend-control bypass or financial control failure
- Human Review Gate bypass
- Data integrity / irreversible migration without plan
- Production outage / failed deploy without rollback
