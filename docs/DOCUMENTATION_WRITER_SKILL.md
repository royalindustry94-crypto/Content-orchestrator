# Documentation Writer skill

Cursor skill: **`documentation-writer`** (`/documentation-writer`).

Package: [`.cursor/skills/documentation-writer/`](../.cursor/skills/documentation-writer/).

Produces and maintains accurate technical and product documentation for
Content Orchestrator — architecture, ADRs, implementation/audit/release docs,
changelogs, migration and RLS/security/ops docs, OpenAPI-aligned API docs.
Never invents functionality; flags doc↔code drift. ADR acceptance remains
`/chief-architect`; release readiness remains `/release-manager`.

See also: [CURSOR_SKILLS.md](./CURSOR_SKILLS.md), [AUTHORITY_MATRIX](../.cursor/skills/AUTHORITY_MATRIX.md).
