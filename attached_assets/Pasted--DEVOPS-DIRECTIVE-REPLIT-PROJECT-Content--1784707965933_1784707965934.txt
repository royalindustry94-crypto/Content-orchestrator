MANDATORY REGRESSION TESTS

Confirm that tests exist and pass for:

1. Spend isolation
   Releasing spend reservations for one pipeline_run_id must not release reservations belonging to another run, including runs in the same workspace.

2. Event-loop prevention
   Processing stage completion or failure must not cause the controller to recursively consume or emit a self-triggering stage.completed or stage.failed loop.

MULTI-TENANT SECURITY VALIDATION

Test that:

- Workspace A cannot read or mutate Workspace B orchestration records.
- Every workspace-scoped query includes workspace_id enforcement.
- Idempotency keys cannot collide across tenants incorrectly.
- Scheduler fairness does not leak work across tenants.
- Worker assignments cannot be claimed across unauthorized workspace boundaries.
- Spend operations cannot affect another workspace or pipeline run.
